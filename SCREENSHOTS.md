# Smylte screenshots

These three images show the packaged **v0.55.15** interface. They were captured in a separate temporary browser profile with made-up posts, authors and locally created images. No personal Library, account session or API key was used.

| Screenshot | What it demonstrates |
| --- | --- |
| [Library](assets/screenshots/library-v0.55.15.png) | Browsing synthetic saved posts in the Library. |
| [Search](assets/screenshots/search-v0.55.15.png) | Finding synthetic saved image text with keyword search. The image text was supplied as test data; this does not measure OCR, AI categorization or meaning-search accuracy. |
| [Downloads](assets/screenshots/downloads-v0.55.15.png) | The download-only controls and result, using a synthetic media response. It does not demonstrate a download from a signed-in live platform. |

The download demonstration uses a local test response instead of requesting a real social-media post. Actual downloads still depend on the supported website, media format, your access and the content loaded during the run. A thumbnail alone is not a saved video.

The screenshots are documentation assets. Application source code, test helpers, browser profiles and installation packages are not included in this public repository. Smylte remains closed source.

Install the current release from the [Chrome Web Store](https://chromewebstore.google.com/detail/smylte-save-social-media/eebefbknmfpjmhggmcapmljjilmkoebg), or read the [product overview and support table](https://yaka310.com/projects/post-library/#supported-sources).
