# Support and FAQ

[Install Smylte](https://chromewebstore.google.com/detail/smylte-save-social-media/eebefbknmfpjmhggmcapmljjilmkoebg) · [Guides](https://yaka310.com/projects/post-library/guides/) · [Report a bug or suggest a feature](https://github.com/bu56co-del/smylte/issues/new/choose)

## Where is my Library stored?

Smylte keeps its Library on your device. Keep the browser profile and any downloaded Library files you rely on. Use Full Backup & Restore before moving to another computer or removing the extension. A JSON export contains records but excludes downloaded media.

## Can I still view a deleted original post?

Successfully saved text, previews and downloaded media remain available while you retain your local copy. Smylte cannot recover content that was never saved, or restore local data you have deleted. A thumbnail is not the full video.

[Read the saved-copy guide](https://yaka310.com/projects/post-library/guides/saved-post-deleted-original/).

## Why did a download stop or show Partial?

A source may require login, change its page layout, limit requests, remove content or use an unsupported media format. Check the source page and the result message. Do not assume a thumbnail, incomplete file or unconfirmed result is a saved video.

If a download is unconfirmed, check Chrome Downloads before starting it again. Smylte separates completed, partial, failed, cancelled and unconfirmed results.

## Does Smylte save every comment?

No. Where supported, choose no comments, the top five by likes, or all comments loaded during that run. The all-loaded option has a 5,000-comment cap per entry; source-specific support and limits vary. Comments the page never loads cannot be saved, and X reply bodies are not copied.

## Do I need an AI API key?

No key is needed for saving, keyword search, local image-text recognition, meaning search or manual organization. Optional cloud AI categorization uses your own Google Gemini API key and may have provider limits or charges. It is separate from local meaning search.

## Why is meaning search taking time to prepare?

Meaning search creates a local index. It uses extra model/index storage and takes time to prepare; its usefulness varies with the wording and language. Keyword search remains available while preparation is incomplete. Meaning search is optional.

## Can I share a saved post?

Create share images from one saved post and explicitly selected saved text comments, up to 10 PNGs. Review each image and any author/source details before exporting. The original Library record is not changed.

## Limits to keep in mind

- Supported content must be accessible to your current browser session and loaded during the run. Smylte does not bypass login, private-content restrictions or site limits.
- Not every video, reply or complete account history can be captured.
- Pinterest supports downloads only; Pins do not become Library records.
- Patreon support is in beta and depends on your existing access.
- X quoted-post media and reply bodies are not copied.
- Media-only downloads do not create Library records. A full backup and JSON record export serve different purposes.
- Image-text recognition can make mistakes. Search and privacy-redaction suggestions should be checked against the image.
- This version does not save general webpages or provide automatic cloud synchronization.

## Reporting a problem

Use the [bug-report form](https://github.com/bu56co-del/smylte/issues/new/choose). Include the Smylte version, Chrome version, operating system, affected action, expected result and actual result. Include a source link only if it is public and you are comfortable sharing it.

GitHub issues are public. Do not attach API keys, passwords, cookies, full backup archives, private posts or screenshots containing personal data. A short redacted error message is usually more useful than a complete activity log. Keep your Library in place while troubleshooting; removing and reinstalling the extension can remove local data.

For a private or security-sensitive report, use the contact information on the [developer's contact page](https://yaka310.com/contact/) instead of a public issue.
