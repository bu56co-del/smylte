# Smylte updates

These are product notes, not downloadable software releases. Install Smylte through the [Chrome Web Store](https://chromewebstore.google.com/detail/smylte-save-social-media/eebefbknmfpjmhggmcapmljjilmkoebg).

## In development — v0.55.16

**Not yet confirmed available in the Store.** These changes have been checked locally.

- Avoid a second video download when the first request was accepted but its confirmation could not be saved.
- Honor Stop before starting a file when download preparation is still pending.
- Keep Restore preview controls locked while a restore is applying changes. Prevent Cancel from claiming that nothing changed after restoration has begun or partially completed.

Existing saved content, settings, supported features and backup formats are preserved. These changes do not promise that every website video or comment can be captured.

## Available in the Store — v0.55.15

Store version and update date checked on **October 24, 2026**.

- Show the Simplified Chinese language choice as **简体中文** across interface languages.

This version also includes recent improvements:

- Better handling of Threads reply placeholders while keeping unsent drafts out of saved content.
- An updated Discord support invite, with Discord kept directly above Support me in the sidebar.
- Up to two small world clocks above Library, with time zones and 12/24-hour preferences in Settings.

See the [Store listing](https://chromewebstore.google.com/detail/smylte-save-social-media/eebefbknmfpjmhggmcapmljjilmkoebg) for current availability and the [website update archive](https://yaka310.com/updates/) for earlier product notes. A development note here does not mean a Store update has been approved or published.
