# About this repository

This is the official public documentation, updates and support repository for **Smylte - Save social media posts, library & downloader**.

The Smylte application is closed source. Its source code, build system, internal development history and installation packages are not published here. A public documentation repository does not make the application open source, and this repository does not grant an open-source license to the application.

Install the application from the [Chrome Web Store](https://chromewebstore.google.com/detail/smylte-save-social-media/eebefbknmfpjmhggmcapmljjilmkoebg). Documentation corrections and user feedback are welcome through GitHub issues. Development notes are not a promise of release dates or Store approval.

Smylte was formerly called Post Library. It is an independent, unofficial tool and is not affiliated with or endorsed by the services it supports. Service names belong to their respective owners.
